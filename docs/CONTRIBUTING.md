# 贡献指南

感谢你对 IMG 项目的兴趣！以下是贡献的指南。

## 如何贡献

### 1. Fork 项目

点击 GitHub 页面右上角的 Fork 按钮。

### 2. 克隆你的 Fork

```bash
git clone https://github.com/YOUR_USERNAME/img.git
cd img
```

### 3. 创建功能分支

```bash
git checkout -b feature/your-feature-name
```

### 4. 提交改动

```bash
git add .
git commit -m "Add: 你的改动描述"
```

### 5. 推送到 Fork

```bash
git push origin feature/your-feature-name
```

### 6. 创建 Pull Request

在 GitHub 上创建 Pull Request，详细描述你的改动。

## 代码规范

- 遵循项目现有的代码风格
- 添加适当的注释
- 更新相关文档
- 确保测试通过

## 问题报告

如果发现 Bug，请在 Issues 中详细描述：
- 问题描述
- 复现步骤
- 期望行为
- 实际行为
- 环境信息

感谢你的贡献！
