# 🖼️ IMG - 图库项目

一个现代化的图库管理系统，用于上传、浏览和分享图片。

## 📋 功能特性

- ✅ 图片上传和管理
- ✅ 分类和标签系统
- ✅ 图片预览和缩略图生成
- ✅ 分享功能
- ✅ 响应式设计

## 🚀 快速开始

### 环境要求

- Node.js 14+ 或 Python 3.8+
- Git

### 安装

```bash
git clone https://github.com/anymater/img.git
cd img
```

### 开发

```bash
npm install
npm run dev
```

或使用 Python:

```bash
pip install -r requirements.txt
python app.py
```
